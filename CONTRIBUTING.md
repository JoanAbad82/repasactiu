# Contributing

Repàs Actiu accepts small, reviewable software and content-quality improvements.

## Before proposing a change

For changes that can affect production behavior or content, run:

```bash
npm run test:all
npm run build
```

## Content rules

- Official teaching material is the academic authority.
- Preserve one unequivocally correct answer per test question.
- Preserve stable IDs and Catalan/Spanish correct-answer index parity.
- Keep source traceability synchronized.
- Do not submit course PDFs, substantial copyrighted excerpts, private answer keys, or private source mappings.
- Research Intake/MoltBook proposals are hypotheses and require independent verification before production.

## Agent / research contributions

For adversarial educational-content hypotheses, ambiguity counterexamples, distractor kill tests, or validator ideas, prefer:

https://github.com/JoanAbad82/repasactiu-research-intake

That surface has no automatic production path.

## Licensing

Software contributions are accepted under the repository's Apache-2.0 software scope. Educational/source-derived content remains subject to the separate rights boundary described in `LICENSE`.
