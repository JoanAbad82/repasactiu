# Repàs Actiu

Plataforma web pública i minimalista de tests en català.

## V1

Curs inicial: **Operacions auxiliars de serveis administratius i generals**.

- Mode Estudi
- Mode Examen
- Mode Repassar errors
- 200 preguntes disponibles
- Sense comptes ni backend
- Progrés local amb `localStorage`
- Cloudflare Pages

Producció: https://repasactiu.pages.dev

### Banc de preguntes

El banc es basa exclusivament en els materials docents originals dels blocs 1, 2, 3 i 5. Les preguntes noves incorporen més casos d’aplicació, comparació entre conceptes pròxims i distractors del mateix àmbit, mantenint una sola resposta inequívocament correcta.

Distribució actual:

- Bloc 1: 42 preguntes
- Bloc 2: 56 preguntes
- Bloc 3: 56 preguntes
- Bloc 5: 46 preguntes

## Desenvolupament

Requereix Node.js 22 LTS.

```powershell
npm install
npm run test
npm run serve
```

## Independència

Repàs Actiu és un projecte independent d’Open Utility Lab.
